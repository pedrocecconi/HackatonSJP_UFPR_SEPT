# Mentorias de 09/10 — aprendizados

*As transcrições brutas foram retiradas dos materiais porque citavam pessoas. Ficam aqui só os aprendizados, sem nomes. O resumo completo, com o que mudamos no produto, está em `PERGUNTAS_MENTORES.md`.*

## Campo
- O usuário não sabe se a equipe está indo e liga para o Help Desk: o **"apagão operacional"**.
- Hoje a OS é impressa e entregue ao técnico; o fechamento é digitado depois.
- Depois de fechada, o Help Desk liga para confirmar; muitas vezes o usuário não está (férias, telefone genérico).
- As equipes se organizam **por região**; o ideal é aproveitar a viagem: "está no lugar X, abriu ordem ali, já faz".

## Processo do Help Desk
- O atendimento por telefone continua; o usuário não abre chamado sozinho.
- O problema maior está **depois que a OS sai do Help Desk**, na parte presencial.
- Técnicos são setorizados (escolas, saúde); terceirizado ou servidor, tratar como "técnico".
- Medir o **deslocamento** à parte: há unidades a 20–35 km.

## Prefeitura, dados e IA
- A barreira é o servidor: a ferramenta **não pode dar mais trabalho** e precisa compensar para ele.
- Precisa **conversar com o legado** (descobrir o nome do sistema do Help Desk).
- Começar pequeno; dados sem nuvem, no datacenter próprio.

## Negócio e método
- Escolher **uma fatia** do problema e ouvir histórias reais.
- Benchmark: operadoras avisam quem vai atender e mostram o técnico a caminho.
- Ter resposta para "por que uma ligação não resolve?".
- Piloto na própria Secretaria; narrativa de economia (combustível, menos viagens, unidade parada).
